# 02. UI Flow — 사용자 경로 · 화면 목록

> 2026-09-24 구현 기준. 입력 단말기(`/`)에서 조회하면 결과 전용 페이지(`/result`)로 이동한다.
> 최초 기획의 종목 미특정 경로는 파이프라인에 남아 있으나 현재 데모는 종목 선택이 필수다.

## FLOW-001 · 공시 사실 대조

```text
앱 방문 → terminal-off ─[전원 켜기]→ idle
?power=on → idle (켜짐 연출 생략)
idle ─[종목 선택 + 8자 이상 문장 + 확인]→ /result: loading
/result: loading → result-fact / result-empty / sample / error
/result ─[다시 조회하기]→ /: 종목·문장·예시 선택 복원
/ ─[직전 결과 보기]→ /result: 저장된 결과 재표시 (새 조회 없음)
/ ─[입력 변경 + 확인]→ /result: loading (새 조회로 교체)
```

- 켜짐 연출은 전원 클릭 직후 한 번만 재생한다. 위젯 조작에 따른 재실행에서는 반복하지 않는다.
- 종목 미선택 시 확인 버튼은 비활성이다. 빈 문장·8자 미만 입력에는 안내하고 조회하지 않는다.
- 입력에는 종목별 보유 공시 안내, 예시 칩, 직접 작성할 수 있는 문장 입력창이 있다.
- 종목 선택은 회사별 요약만 갱신한다. 안내를 위해 전체 코퍼스를 읽거나 조회 로딩 상태로 넘어가지 않는다.
- 유효한 조회를 시작하면 즉시 결과 전용 페이지로 이동한다. 조회 기준과 대기 안내·경과 시간을
  먼저 보여주고, 완료되면 같은 페이지에서 사실 대조와 맥락으로 교체한다. 대기 중 복귀 버튼과
  개발자 옵션은 비활성이다. CRT와 입력 위젯은 표시하지 않는다.
- 사실의 근거 번호를 누르면 해당 원문 위치로 이동한다. 같은 섹션을 공유하는 사실은 원문을
  한 번만 표시하며, 같은 공시의 다른 섹션은 별도 근거로 유지한다.
- 다시 조회하기는 입력 초안을 복원한다. 입력 화면의 직전 결과 보기는 재조회 없이 저장된
  결과를 연다. 초안과 조회 기준이 다르면 “이전 조회 결과” 안내를 표시한다.
- 저장 결과가 없는 새 세션에서 `/result`에 진입하면 안내와 다시 조회하기 버튼을 제공한다.
  직전 결과는 세션에 보관한다. 완료된 결과는 별도 조회 기록에서도 열 수 있다.
  URL 자체가 특정 결과를 저장하거나 공유하지는 않는다.
- 결과의 공시 원문에서 표현을 매칭해 공시 유형·회사별 사용 이력·검증된 반복 경향을 설명한다.
  맥락을 제시할 수 없을 때도 이유를 한 줄 안내한다. 사후 이벤트 예측 통계는 표시하지 않는다.
- 오류 시 실패한 조회의 종목·문장과 재시도 안내를 유지한다. 설정 정보는 접힌 기술적 상세에
  제공한다. 재시도 성공 시 이전 오류를 지운다.
- `NotImplementedError` 샘플 폴백은 남아 있으며 샘플 표시를 반드시 붙인다.

## FLOW-002 · 화법 문구 단독 검색 — 이전 경로

`pipeline.py`와 `ReportCard.phrase_stats`에는 호환성을 위해 남아 있다. 현재 SCR-001의
종목 선택 필수 UI에서는 종목 미특정으로 이 경로에 진입하지 않는다. 새 화면 구현의 기준으로
사용하지 않는다.

## FLOW-003 · 공시 용어 사전

앱 방문 → 사전 탭 → 용어 검색 → 정의·출처 확인. 검색 결과가 없으면 안내를 표시한다.
이 흐름은 단말기 전원이나 팩트체크 실행을 요구하지 않는다.

## FLOW-004 · 조회 기록

조회 완료 → 최근 30건 메모리 보관 → 사전 옆 **조회 기록** 탭 → 왼쪽 서류 선택 → 오른쪽
조회 당시 문장·사실·출처·맥락 확인. 결과 페이지의 **조회 기록** 버튼으로도 들어간다.

- 최신순 목록에 종목·문장 요약·조회 시각·서류 번호를 표시한다. 같은 문장도 별도 서류다.
- 결과와 맥락을 다시 계산하지 않으며 프린터 연출을 반복하지 않는다. 입력 초안도 유지한다.
- 900px 이하에서는 목록 위·문서 아래로 쌓고, 목록만 최대 240px 안에서 스크롤한다.
- 새로고침·새 탭에서도 같은 앱 서버가 실행 중이면 기록을 열 수 있다. 서버 재시작·캐시 삭제로
  비워지는 임시 보관이며, 같은 서버에 접속한 세션들이 공유한다. 서버가 다르면 기록도 다르다.
- 실패한 조회는 서류로 추가하지 않는다. 기존 기록은 유지한다. 정상 빈 결과·샘플은 표시 내용을
  그대로 보관하고 샘플에는 표시를 붙인다. 기록이 없으면 안내와 입력 탭 이동 버튼을 제공한다.
