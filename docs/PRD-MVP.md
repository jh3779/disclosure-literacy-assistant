## 1. 배경

LG CNS AI 캠퍼스 교과목 3 팀 프로젝트. 교과목 2(LLM 서비스 및 고급 RAG 인프라 구축)에서
배운 문서 로딩·청킹·임베딩·벡터 저장소·검색 품질·신뢰성 평가를 하나의 RAG 서비스로
통합하는 것이 목표.

강사가 강조한 프로세스: 코드보다 먼저 **문제 정의 → 경쟁 서비스 리서치 → 방향 설정**을
거칠 것. "경쟁성 검토 없이 바로 만들지 않는다"는 원칙이 명시적으로 안내됨(day-27).

## 2. 주제 결정 경위

- **1차 탐색(2026-09-07~08)**: "코드 리뷰 성장 코치 에이전트"(review-coach)와 "도메인 특화
  지식 응답 RAG" 11개 후보를 조사·설계했으나, 경쟁 서비스 리서치 끝에 팀은 이 방향으로
  가지 않기로 했다 — 관련 문서는 커밋 이력에 남아있음(PR #5/#9/#10/#11, 전부 폐기).
- **2차 결정(2026-09-09)**: "미스터리 추론 캘리브레이션 게임"(`narrative_qa/`) 채택. 팀원
  (powercodingman/9abin)이 이미 L0~L2+L5 코드를 상당 부분 구현한 상태로 합류(PR #12).
  L3 게임 로직은 착수 전이었다.
- **3차 재피벗(2026-09-10)**: 금융 도메인으로 재정립. 16개 금융 아이디어(약관 독해,
  분쟁조정 사례, DART 공시, 소상공인 정책자금, 금융 문해력 교육 등)의 **데이터 가용성을
  직접 검증**(DART OpenAPI 무료 발급 확인, 공공데이터포털 등)하고, 그중 3개 세부 아이디어
  ("카드 소비→가상 포트폴리오", "테마주 루머 팩트체커", "공시 국어사전")를 자본시장법
  유사투자자문업 리스크·경쟁 서비스(공시줍줍/한경 유레카 등) 관점에서 검토한 끝에, 루머
  팩트체커와 공시 국어사전을 통합한 **"공시 리터러시 어시스턴트"**로 확정했다(PR
  #14~#16). "카드 소비→가상 포트폴리오" 아이디어는 규제 리스크가 높아 보류했다.
  `narrative_qa/` 코드는 레포에 남아 있으나 현재 작업 대상이 아니다.

## 3. 스택 (확정)

- **데이터**: DART OpenAPI(공시 원문·재무정보 — 무료·즉시 발급 확인됨), KIND(자율공시),
  공매도·지분공시
- **LLM**: provider 스왑(`narrative_qa/llm.py::complete` 재사용 예정) — openai/anthropic/
  gemini, 팀원마다 달라도 됨
- **임베딩**: 미확정 — Phase 1에서 결정(로컬 `dragonkue/BGE-m3-ko` 재사용이 유력 후보)
- **패키지 매니저**: uv, Python 3.12

## 4. 핵심 원칙

- **투자 추천 금지**: 매수/매도 판단, 목표가, 등급·신호등을 일절 출력하지 않는다 —
  자본시장법상 유사투자자문업 회피가 최우선 설계 제약이다.
- 긍정/부정 사실은 항상 동일 비중으로 노출한다.
- 화법통계는 표본 부족 시 통계적으로 유의하지 않음을 명시한다.

자세한 근거는 [proposals/finance-pivot/03-integrated-proposal.md](proposals/finance-pivot/03-integrated-proposal.md)
7절(규제 리스크 및 대응) 참고.
