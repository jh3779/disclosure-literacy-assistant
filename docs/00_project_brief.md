## 한 문장 정의

이 제품은 커뮤니티/유튜브발 테마주 루머를 접했거나 공시의 상투적 IR 화법을 이해하지
못하는 개인투자자가, DART 공시 원문 대조와 과거 화법 통계만으로 5분 안에 1차 검증하도록
돕는다 — 시스템 자신은 매수/매도 판단을 절대 내리지 않는다.

## 문제 · 목표 (왜)

- **푸는 문제:** 개인투자자는 두 갈래 정보 비대칭에 노출돼 있다 — (1) 커뮤니티 루머가
  실제 공시로 뒷받침되는지 모름, (2) 실제 공시를 읽어도 상투적 IR 화법("적극 검토 중",
  "확정된 바 없음" 등)이 과거 통계적으로 무엇을 의미했는지 모름.
- **현행 대안:** 직접 DART에서 원문을 찾아 읽거나(진입장벽 높음), 공시줍줍 같은
  기자 수작업 편집 뉴스레터에 의존하거나(자동화 안 됨, 커버리지 제한), 커뮤니티 여론을
  그대로 믿는다(근거 없음).
- **성공 시 변화:** 사용자가 "공시에 실제로 뭐라고 쓰여 있는가 / 과거 패턴이 통계적으로
  어땠는가"라는 사실 기반 근거를 스스로 확인하게 된다. 최종 투자 판단은 항상 사용자 몫.

## 대상 사용자 · 맥락

| 항목 | 내용 |
| --- | --- |
| 1차 사용자 | 커뮤니티/유튜브에서 테마주 루머를 접한 개인투자자 |
| 1차 사용자(변형) | 공시·IR 자료를 읽지만 상투 화법의 함의를 모르는 개인투자자 |
| 2차 사용자/수신자 | LG CNS AI 캠퍼스 교과목 3 강사·평가자(발표 데모 관람) |
| 사용 맥락 | 웹(Streamlit 데모), 투자 판단 전 "5분 안에 1차 검증"하려는 비동기 조사 상황. 발표 데모 기준 응답 10초 이내(DESIGN.md 성공 지표) |

## 핵심 가치 · 성공 지표

- **핵심 가치:** "공시에 실제로 뭐라고 쓰여 있는가 / 과거 패턴이 통계적으로 어땠는가"까지만
  다루고, 등급·신호등·매수매도 추천은 일절 만들지 않는다(자본시장법상 유사투자자문업
  회피가 최우선 설계 제약).
- **성공 지표(DESIGN.md 원문):**
  - 팩트체크: gold set 대비 정밀도·재현율 각 80% 이상
  - 화법통계: 표본 20건 이상인 클러스터 15개 이상 확보
  - 데모: 루머 입력 → 결과 카드 출력까지 응답시간 10초 이내
- **반드시 지킬 품질:** 규제 중립성(투자 판단 배제), 사실 정확성(groundedness — 근거
  없는 사실 나열 금지), 긍정/부정 사실 동일 비중 노출.

## 비전 대비 MVP 경계 (요약)

MVP는 코스피·코스닥 상장사 대상, 루머 팩트체크(L2a)+화법통계(L2b)를 입력창 하나로
자동 분기하는 통합 데모까지. 실거래 연동·알림·포트폴리오·계정/로그인은 명시적으로
범위 밖([01_requirements.md](01_requirements.md) Won't 참조).
