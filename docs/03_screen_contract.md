# 03. 화면 계약 (Screen Contract)

> 2026-09-24 구현 기준 — `disclosure_lit/demo/app.py`, `demo/terminal.py`.

## SCR-001 · 팩트체크·화법통계 (`/`)

- **목적:** 선택한 종목의 공시와 대조할 문장 입력 및 조회 실행.
- **상시 표시:** 서비스 제목·투자 판단 미제공 안내, 팩트체크/사전/조회 기록 탭.
- **입장:** 꺼진 CRT와 키보드로 조작 가능한 “전원 켜기” 버튼. `?power=on`이면 바로 입력 가능.
- **입력:** 종목 선택, 보유 공시 요약, 예시 칩, 문장 입력, 확인 버튼, 접힌 사용 안내.
- **종목 선택:** 선택한 회사의 로컬 공시 요약만 갱신·캐시한다. 전체 코퍼스 로딩이나 사실
  대조를 시작하지 않는다. 실제 조회 로딩은 확인 버튼을 눌렀을 때 표시한다.
  선택값 삭제(X) 버튼은 숨기고 종목 검색·목록 펼치기·다른 종목으로 변경은 유지한다.
- **조회 시작:** 유효한 입력이면 즉시 SCR-003으로 이동해 조회한다. 잘못된 입력은 이 화면에서 안내한다.
- **입력 보존:** 결과 화면에서 돌아오면 종목·문장·예시 선택을 복원한다. 전원 켜짐 연출은 반복하지 않는다.
- **직전 결과 보기:** 결과 또는 오류가 있으면 제공한다. SCR-003으로 이동하며 새 조회는 하지 않는다.
- **개발자 옵션:** 기본 접힌 사이드바 안에 기존 샘플 옵션을 유지한다.

| 상태 | 반드시 보여야 하는 것 |
| --- | --- |
| terminal-off | 꺼진 단말기, 전원 버튼. 조회 입력 위젯 없음 |
| idle | 켜진 단말기, 종목·문장 입력. 종목 미선택 시 확인 비활성 |
| 입력 부족 | 빈 문장 또는 8자 미만 안내. 새 조회는 실행하지 않음 |

## SCR-002 · 사전

입력 페이지의 탭이다. 단말기 전원과 무관하게 용어 검색, 정의, 출처를 제공한다.
밝은 배경과 본문용 서체를 쓴다.

## SCR-003 · 조회 결과 (`/result`)

- **목적:** 조회 결과를 페이지 상단부터 읽을 수 있도록 입력 화면과 분리한다.
- **상시 표시:** 대기 중 “공시 대조 중”, 완료 후 “공시 대조 결과” 제목, 투자 판단 미제공 안내,
  다시 조회하기·조회 기록 버튼. 대기 중에는 두 이동 버튼과 개발자 옵션을 비활성화한다.
- **결과:** 밝은 출력물에 조회 당시 종목·문장, 동일 비중의 뒷받침/배치 사실,
  근거 원문·DART 링크, 서술형 맥락 지도 또는 맥락 미표시 이유를 표시한다.
- **출력 연출:** 결과 상단에 장식용 프린터 배출구를 둔다. 새 조회가 성공하면 한 장의 종이가
  아래로 펼쳐지는 1초 연출을 한 번 재생한다. 오류·직전 결과 재열람·일반 재실행은 즉시 표시한다.
  무음이며 모션 축소 설정에서는 연출 없이 표시한다.
- **조회 기준:** 종목과 입력 문장을 출력물 상단에 표시한다. 문장은 16px 일반 텍스트로 한 번만
  표시하며 사용자 입력을 Markdown으로 해석하지 않는다. 오류에서도 실패 당시 조회 기준을 보존한다.
- **근거 연결:** 사실마다 근거 번호 링크를 제공한다. 동일한 섹션은 하나의 원문 펼침으로 합치고,
  같은 공시 안의 다른 섹션은 유지한다. 펼침 제목은 번호·서식·섹션명·공시일을 포함한다.
- **복귀:** 다시 조회하기는 SCR-001로 이동한다. 저장된 결과와 입력 초안을 유지한다.
- **결과 보존:** 입력 초안을 바꾼 뒤 직전 결과를 열면 “이전 조회 결과”임을 명시한다.
- **표시 범위:** CRT·입력 위젯·사전 탭은 이 페이지에 표시하지 않는다.
- **세션 범위:** 새 세션에 저장 결과가 없으면 안내와 복귀 버튼을 표시한다. 영구 저장·공유 링크가 아니다.

| 상태 | 반드시 보여야 하는 것 |
| --- | --- |
| loading | 조회 기준, 대기 제목·설명, 첫 조회 지연 안내, 스피너·경과 시간 |
| result-fact | 사실 대조·출처·맥락 영역 |
| result-empty | 관련 공시를 찾지 못했다는 안내 |
| previous-result | 조회 당시 입력 + 현재 입력과 다르다는 안내 + 직전 결과 |
| error | 실패한 조회 기준 + 재시도 안내 + 접힌 기술적 상세. 기본 traceback 노출 없음 |
| sample | 실제 결과로 오인하지 않도록 샘플 캡션 |
| 저장 결과 없음 | 표시할 결과가 없다는 안내 + 다시 조회하기 |

## SCR-004 · 조회 기록

- **진입:** `/`의 사전 옆 세 번째 탭. 전원과 무관하게 접근한다. `/result`에서도 이동 가능하다.
- **구성:** 최대 1200px 작업 영역, 왼쪽 최신순 서류 목록과 오른쪽 밝은 출력물.
- **선택:** 네이티브 라디오로 한 서류를 고른다. 선택 배경·테두리·라디오 상태와 키보드 포커스를
  표시한다. 종목, 최대 70자 문장 요약, 한국 시각, 고유 서류 번호로 같은 조회도 구분한다.
- **본문:** 원문 전체와 조회 시각, 사실, 근거, 당시 맥락을 표시한다. 재조회·재계산·출력 연출 없이
  읽는다. 현재 입력 초안과 비교한 이전 결과 경고는 붙이지 않는다.
- **보관:** 앱 프로세스 메모리의 최근 30건. 같은 서버의 새 탭·새 세션에서도 보이며 재시작·캐시
  삭제로 초기화된다. 31번째 조회부터 가장 오래된 서류를 제외한다. 디스크 저장·공유 URL은 없다.
- **빈 상태:** 아직 보관된 결과가 없다는 안내와 문장 조회하기 버튼. 실패는 기록에 추가하지 않는다.
- **적응형:** 900px 이하에서 목록 위·문서 아래. 목록 최대 240px 세로 스크롤. 1100px 이하에서는
  출력물의 두 사실 그룹도 세로로 쌓는다. 데스크톱 목록은 최대 660px 안에서 스크롤한다.

## 시각·접근성 계약

- 앱 배경은 원본 레퍼런스의 방·책상 이미지를 로컬 정적 파일로 제공한다. 비율을 유지해 화면을
  채우고 어두운 막을 얹는다. 입력 CRT와 결과 출력물의 배경은 불투명하게 유지한다.
- 레트로 연출은 입장·입력 영역에 한정한다. 본문과 결과는 Pretendard, 짧은 장비·부팅 문구만 Galmuri.
- 전원 LED는 켜짐/꺼짐 텍스트와 함께 표시한다. 전원 애니메이션은 한 번만 재생한다.
- 켜진 CRT의 잔잡음·주사선·간섭 띠는 입력 영역 안에만 표시한다. 입력 포커스에서는 효과를
  완화하고 모션 축소 설정에서는 정지시킨다. 장식 레이어는 클릭·키보드 조작을 가로막지 않는다.
- `prefers-reduced-motion: reduce`에서는 연출을 끈다. 폰트는 로컬 번들로 제공한다.
- 320px·400px 화면에서 가로 스크롤 없이 사용 가능해야 한다. 모바일 결과 컬럼은 세로로 배치한다.
- 주요 입력·복귀 버튼과 종목 선택의 펼치기 버튼은 최소 44px 높이로 제공한다.
  예시 칩은 문장을 생략하지 않고 줄바꿈한다.
- 페이지 제목 H1 → 사실 대조·맥락 H2 → 사실 그룹·근거 원문 H3 계층을 유지한다.
  근거 링크·원문 펼침에는 키보드 포커스를 표시한다.
- 등급·점수·별점·신호등·투자 권유를 만들지 않는다. 긍정/부정을 색으로 구분하지 않는다.
- 사후 이벤트 예측 카드와 `result-phrase-only` 목업은 이전 설계 자료이며 현행 UI 계약이 아니다.
