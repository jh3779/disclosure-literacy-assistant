# 데모 배경 처리 기록

## 2026-09-29 — 외부 이미지 제거, CSS 자체 제작으로 교체

저장소 공개 준비 과정에서 **외부 사이트의 배경 이미지를 걷어냈다.** 시연용으로 한때
레퍼런스 사이트의 JPEG를 로컬에 두고 썼는데, 공개 저장소에서는 제3자 저작물 재배포에
해당하므로 파일과 그 출처 기록을 함께 삭제했다.

대체 구현은 `demo/static/retro.css`의 `.stApp` 규칙이다 — **이미지 파일 없이 CSS
그라데이션 세 층**으로 방을 표현한다.

| 층 | 역할 |
| --- | --- |
| `radial-gradient` (위) | 단말기 주변으로 떨어지는 따뜻한 조명 |
| `radial-gradient` (아래) | 화면 가장자리를 눌러주는 비네트 |
| `linear-gradient` | 벽에서 책상으로 넘어가는 수직 변화 |

### 이 방식의 이점

- **배포 제약이 없다** — 저장소를 공개해도 문제되지 않는다
- **요청이 하나 줄어든다** — 이미지 파일을 받지 않으므로 첫 렌더가 빠르다
- 화면 크기에 따라 깨지지 않는다(비트맵 확대 없음)

### 확인 방법

`streamlit run disclosure_lit/demo/app.py` 후 입력·결과 화면에서 배경이 어둡게 깔리고
본문 가독성이 유지되는지 본다. 이전 스크린샷(`docs/testing/terminal-ui/`)은 삭제된
배경이 찍혀 있어 함께 제거했다 — 필요하면 현재 화면으로 다시 촬영한다.
