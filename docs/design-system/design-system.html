F-01디자인 원칙00_project_brief · PRD-MVP.md 4절
balance저울처럼
뒷받침하는 사실과 배치되는 사실은 항상 같은 배경·크기·위치로 나란히 놓는다. 어느 한쪽이 먼저 나오거나 더 크게 보이지 않는다.
REQ-F-006
block신호등이 아니라 사실판
등급·점수·별점·게이지·매수매도 추천은 이 시스템에 존재하지 않는다. 색으로 "좋다/나쁘다"를 암시하는 어떤 표현도 금지 — 자본시장법상 유사투자자문업 회피가 최우선 제약.
REQ-F-006·007 · PRD-MVP 4절
description근거는 항상 펼쳐볼 수 있게
모든 사실 항목은 근거 공시 원문(rcept_no)으로 연결된다. 근거 없는 사실 나열은 하지 않는다 — groundedness가 규제 방어선의 실질적 구현이다.
REQ-F-005
warning표본 부족은 숨기지 않는다
클러스터 표본이 부족하면(예: 3건 이하) 수치를 강조하지 않고 경고만 보여준다. tertiary(amber)는 이 의미 하나에만 쓴다 — 다른 곳에 재사용 금지.
REQ-F-007 · STATE-002 INV-03
person비전문 투자자 언어
1차 사용자는 전문 애널리스트가 아니라 일반 개인투자자. "groundedness 실패" 대신 "관련 공시를 찾지 못했습니다"처럼 쓴다. 등급 대신 사실 문장으로 말한다.

F-02ColorScheme — "Ledger Blue"M3 tonal targets · Light/Dark 명시 정의
"Ledger"(공식 장부)는 공시(disclosure filing)라는 도메인을 가리키는 이름. 차분한 블루는 문서·기관의 톤이지 매수 신호가 아니다. 아래 스와치는 현재 테마 기준(우상단 토글로 Light/Dark 확인). 구현 시 이 HEX를 그대로 쓴다.

secondaryL #55607B · D #BEC6E4
secondary-containerL #DAE2F9 · D #3D4661
tertiary — 표본부족 전용L #6E5B1E · D #DCC56F
error — 시스템 오류 전용L #BA1A1A · D #FFB4AB

역할 규칙: primary = 버튼·포커스·링크만 · tertiary = "표본 부족 경고" 단 한 곳 · error = DART API 호출 실패 등 시스템 오류만 · 긍정/부정 사실 카드에는 어떤 상태색도 쓰지 않는다(F-03 참고, 의도적 이탈).
